
Completed an Exploratory Data Analysis (EDA) project using Python, Pandas, NumPy, Matplotlib and Seaborn.

The project includes:

1. Calculated descriptive statistical measures such as mean, median, standard deviation, minimum, maximum and quartiles.
2. Created correlation heatmaps to understand relationships between numerical variables.
3. Generated histograms to analyze data distributions.
4. Created box plots to identify potential outliers and unusual values.
5. Formulated three business hypotheses related to customer segments, discounts and sales revenue.
6. Performed statistical hypothesis testing where the available data supports it.
7. Summarized the top five business insights using Markdown commentary.

Tools Used:
Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy and Jupyter Notebook.

Expected Deliverable:
A Jupyter Notebook containing statistical analysis, visualizations, hypothesis testing and business insights.
